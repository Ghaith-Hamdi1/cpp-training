# Introduction to Coding rules

- Coding rules include:
  - Coding guidelines related to the use of programming language facilities
  - Coding style to have a tidy and well formed source code with well defined naming convension for classes, functions, members, ...
- Developers within a project should be aware of the used coding rules and follow them

- Coding guidelines or standards try to avoid errors that are caused by code poorly written i.e. using programming language facilities in a way that make them vulnerable to errors or make the meaning not clear.
- There are multitude of coding guidelines
- MISRA coding rules is one of the most famous rules
- Also, Autosar C++ 14 coding rules, for example, is spreadly used in automotive domain
- These rules or guidelines are checked using static code analyzers (cppcheck, codesonar, ...)

## AUTOSAR C++14

- AUTOSAR C++14 are coding guidelines "for the usage of the C++14 language, in the safety-related and critical environments, as an update of MISRA C++:2008, based on other leading coding standards and the research/analysis done by AUTOSAR"

## Code Style

- Code style is also a set of rules that fix the form of the source code e.g.
  - Tabulation or space for code source indentation
  - Position of the braces {}
  - Spaces before and after signs
