C++ IN MOTION · #84 / 6

The code

int x = 1, y = 2;

const int* a = &x;
a = &y;       // ok
*a = 5;       // error

int* const b = &x;
b = &y;       // error
*b = 5;       // ok

const int* and int const* are the same type. Only the position of const after the * changes the meaning.
