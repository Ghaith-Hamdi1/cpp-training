C++ IN MOTION · #75 / 6

The classic bug

Player* make() {
    Player p;
    return &p;       // p dies at the }
}

Player make() {
    return Player();  // fine
}

The first returns a dangling pointer.

Returning the object by value is safe, and the compiler usually builds it straight in the caller, with no copy.
