Every expression is an lvalue, an xvalue or a prvalue.

Not just two kinds.

x                // lvalue
std::move(x)     // xvalue
x + 1            // prvalue

Since C++11 there are three basic categories. The words lvalue and rvalue are groups of them.

One more catch

void take(std::string&& s) {
    // s is an lvalue here
}

take(make());

The type is an rvalue reference. The expression s is an lvalue.

A name always makes an lvalue. That is why you write std::move(s) again to pass it on.
