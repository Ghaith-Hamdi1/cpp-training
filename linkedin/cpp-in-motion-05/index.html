C++ IN MOTION · #53 / 6

static_cast

double d = 3.9;
int i = static_cast<int>(d);   // 3

Base* b = new Derived;
Derived* p = static_cast<Derived*>(b);

The everyday cast. Numbers, and pointers up or down a class hierarchy.

Downcasting is a promise.

If b is not really a Derived, the behaviour is undefined. Nothing checks it.

C++ IN MOTION · #54 / 6

dynamic_cast

if (auto* p =
        dynamic_cast<Derived*>(b)) {
    // b really is a Derived
}

The same downcast, but checked at run time.

  • a pointer gives nullptr if it is wrong
  • a reference throws std::bad_cast
  • needs a virtual function in Base

It costs a lookup. If you use it a lot, a virtual function is usually the better design.

C++ IN MOTION · #55 / 6

The two you rarely need

const_cast
legacy(const_cast<char*>(s));

For an old function that takes char* but only reads. Writing to an object that was declared const is undefined behaviour.

reinterpret_cast
auto* bytes =
    reinterpret_cast<const unsigned char*>(&x);

Reading an object as bytes is allowed. Reading it as another type is not. For that, use memcpy or std::bit_cast.
