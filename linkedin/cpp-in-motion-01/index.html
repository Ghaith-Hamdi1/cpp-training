*p means: go to the address stored in p.

Then use what is there.

int x = 7;
int* p = &x;
int y = *p;   // 7

That is dereferencing. The star appears in two jobs, and this is the second one.

What is in memory

&x is the address of x. A pointer is just a variable that holds one.

C++ IN MOTION · #13 / 6

Read it, write it

int y = *p;    // read: y is 7
*p = 9;         // write: x is now 9

*p is x, not a copy of it.

Assign to *p and you assign to x.

I ran it: y stayed 7, and x became 9.

C++ IN MOTION · #14 / 6

Pointer to a struct

struct Player { int hp; };

Player player;
Player* q = &player;

(*q).hp = 20;
q->hp = 20;     // the same thing

-> is a shortcut for "dereference, then pick a member".

The parentheses in (*q).hp are needed because . binds tighter than *.
