C++ IN MOTION · #95 / 6

The trap: a reference that outlives

auto make() {
    int n = 5;
    return [&n] { return n; };   // n is gone
}

The lambda now holds a dangling reference.

Fix: capture by value, [n].

Capture by reference only when the lambda is used and finished while the variable is still alive.
