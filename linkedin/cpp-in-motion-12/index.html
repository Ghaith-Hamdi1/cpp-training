C++ IN MOTION · #123 / 6

public: "is a"

class Dog : public Animal {};

Dog d;
Animal& a = d;     // ok
d.name();          // ok

A Dog can be used anywhere an Animal is expected.

This is the one you use for polymorphism. Everything else is the exception.

C++ IN MOTION · #124 / 6

private: "built with"

class Stack : private std::vector<int> {
public:
    void push(int x) { push_back(x); }
};

Stack s;
s.push(1);        // ok
s.push_back(2);   // error

The base is an implementation detail. Outsiders cannot see it or convert to it.

Often a data member does the same job more clearly.
