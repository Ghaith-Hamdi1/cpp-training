# Encapsulation and abstraction

- Encapsulation: OOP concept that allows hiding details about object implementation from user
  - User then accesses the object using public interfaces that manage the how to access data and that protects the object implementation
  - Leads to have all member variables private (or protected for inheritance)
  - Access functions:
    - Getters: used to get the value of private member variables
    - Setters: used to set the value of private member variables
- Abstraction: OOP concept that aims to hide objects data from outside world and provide only the necessary information.
  - Using separate header and source files
  - Use access specifiers to put public only the information that should be presented to user
