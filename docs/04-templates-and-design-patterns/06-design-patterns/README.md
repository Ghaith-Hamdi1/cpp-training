# Introduction to Design Patterns

- Design patterns are typical solution that has been created to resolve commonly occuring problems in software design (not only for C++)
- Design patterns are a toolkit of tried and tested solutions to common problems in software design. Even if you never encounter these problems, knowing patterns is still useful because it teaches you how to solve all sorts of problems using principles of object-oriented design.
- There are a multitude of design patterns, the list is long and we cannot detail all of them during this training, but we will try to see some examples

- Here is a list of some famous desing patterns:

| Column 1 | Column 2 |
|---|---|
| Singleton | Observer |
| Strategy | Decorator |
| State | Visitor |
| Factory | Memento |
| Adapter | Template Method |
| Bridge | Command |

*(the source slide displays these 12 pattern names as a two-column list, reproduced above as a table purely to preserve the two-column layout; only Singleton, State and Strategy are elaborated further in this module)*
