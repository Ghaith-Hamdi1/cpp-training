# Docs

Everything that supports the interactive lessons, grouped by what it is for.

| Folder or file | What it is |
|---|---|
| [`study-checklist.md`](study-checklist.md) | A step-by-step plan through the lessons. Generated by `tools/build-checklist.mjs`; the interactive version with clickable boxes is on the [site](https://ghaith-hamdi1.github.io/cpp-training/study-checklist.html). |
| [`topic-map.md`](topic-map.md) | Where each topic appears in the training notes, the recaps and the lessons. |
| [`reading/`](reading) | The **[C++ roadmap](reading/roadmap/README.md)** (eight phases across all five books, with chapters, pages and time estimates), then reading material for the five reference books in `books/`: a **reading guide** per book (which sections matter and which lesson section each deepens) and a **reading plan** per book (an ordered path in sessions, with checkpoint questions). Session notes templates are in [`notes/`](reading/notes). |
| [`training-notes/`](training-notes/README.md) | The company training course as per-topic Markdown, in four modules (C++ basics, OOP, the standard library, templates and design patterns), with matching code under [`examples/course/`](../examples/course). |
| [`learncpp-recaps/`](learncpp-recaps/README.md) | Personal recaps of the learncpp.com chapters, with solved exercises under `solutions/`. Slower and more thorough than the training notes. |
| [`maintaining/`](maintaining) | For whoever edits the site: the [lesson template](maintaining/lesson-template.md) (how to write a lesson, quiz and example), plus the [content audit](maintaining/content-audit.md) and [rewrite plan](maintaining/content-rewrite-plan.md) that shaped the current lessons. |
