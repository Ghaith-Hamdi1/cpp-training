# Access specifiers

Note: this topic appears twice in the source deck (non-consecutively); both occurrences are preserved below in their original order.

- C++ classes has 3 access specifiers:
  - "public": visible from the inside and outside of the class
  - "protected": visible from inside and child classes
  - "private": visible only inside the class

---

- C++ possible access specifiers: public, protected and private
- Any class member function / attribute that is:
  - public: can be used inside the class and from calling objects
  - protected: can be used inside the class and from child classes if any
  - private: can be used only inside the class
