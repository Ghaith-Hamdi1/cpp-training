# Introduction to OOP

- Procedural programming:
  - List of instructions into functions combined together
  - Data and functions are separate entities
  - Manage combination of both of them to get desired result
- What leads us to use OOP?
  - Everything around us are objects: tables, seats, doors, food, cars, PCs, .....
  - Objects
    - Properties (attributes)
    - Behavior (methods)
- Object Oriented Programming advantages
  - Easier way for code maintenance / enhancement (modular code)
  - Tie together data and behavior
  - Intuitive way to work with data
