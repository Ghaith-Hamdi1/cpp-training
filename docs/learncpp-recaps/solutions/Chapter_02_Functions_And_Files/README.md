# Chapter 2 - C++ Basics: Functions and Files

This chapter introduces how to write, call, and organize functions in C++. It covers function return values, parameters, local scope, forward declarations, multi-file programs, the preprocessor, header files, header guards, namespaces, and basic program design principles.
