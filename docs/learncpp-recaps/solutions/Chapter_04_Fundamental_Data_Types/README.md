# Chapter 4 - Fundamental Data Types

This chapter introduces the fundamental (primitive) data types built into C++: integers, floating-point numbers, booleans, chars, and void. It covers how data is stored in memory, sizes and ranges of each type, type conversion, and common pitfalls when working with these types.
