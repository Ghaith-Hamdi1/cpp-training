# Algorithm library

(Slide 37 — overview)

- Standard library comes with a set of predefined algorithm functions that facilitate some standard processing like searching, sorting, counting... that are applied generally to containers
- Three categories are provided:
  - **Inspectors**: no modifications are brought to containers, e.g. searching and counting elements
  - **Mutators**: modify containers, e.g. sorting, shuffling
  - **Facilitators**: generate a result based on the value of the data member
