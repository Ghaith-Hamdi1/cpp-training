# Variables and types

- A variable is a region of memory that has a value and an identifier (name)
  - Instantiation will be at runtime

```cpp
TYPE variable_name = value;
```

- A type will tell the compiler how to deal with the variable
  - Should be known at compile time
- Two categories of types:
  - Native C++ types (e.g. `char`, `int`, `unsigned char`, `unsigned int`, ...)
  - User defined types
