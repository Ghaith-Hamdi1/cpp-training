# Chapter 28 - Input and Output (IO)

This chapter covers the C++ iostream library: stream-based I/O, formatting, string streams, input validation, and file I/O.

## Projects

| #   | Folder                  | Concept                                                             |
| --- | ----------------------- | ------------------------------------------------------------------- |
| 01  | `01_StreamHierarchy`    | The iostream class hierarchy and the four standard streams          |
| 02  | `02_InputWithIstream`   | Reading input with `>>`, `get()`, `getline()`, `ignore()`, `peek()` |
| 03  | `03_OutputFormatting`   | Formatting output with flags, manipulators, `setw`, `setprecision`  |
| 04  | `04_SetW_NonPersistent` | Demonstrating that `setw()` only applies to the next output         |
| 05  | `05_StringStreams`      | Using `istringstream`, `ostringstream`, and `stringstream`          |
| 06  | `06_StreamStates`       | Stream state flags: `goodbit`, `badbit`, `eofbit`, `failbit`        |
| 07  | `07_InputValidation`    | Validating input, clearing errors, discarding bad data              |
| 08  | `08_BasicFileIO`        | File streams: `ifstream`, `ofstream`, file modes, RAII              |
| 09  | `09_RandomFileIO`       | Random file access with `seekg()`, `seekp()`, `tellg()`, `tellp()`  |
| 10  | `10_CommonPitfalls`     | Mixing `>>` and `getline()`, `endl` vs `'\n'`, and other traps      |
