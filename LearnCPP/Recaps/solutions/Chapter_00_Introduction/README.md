# Chapter 0 - Introduction / Getting Started

This chapter introduces what C++ is, where it came from, and how programs go from source code to a running executable. It covers setting up a development environment, writing your first program, and configuring your compiler for best practices (extensions, warnings, language standard).

Since most of Chapter 0 is about IDE/compiler setup, these projects focus on concepts that **can** be demonstrated in code.

## Projects

| #   | Project                  | Concept                                                                |
| --- | ------------------------ | ---------------------------------------------------------------------- |
| 01  | 01_HelloWorld            | Your first C++ program - the classic "Hello, world!"                   |
| 02  | 02_ProgramStructure      | Basic anatomy of a C++ program (main, return, statements)              |
| 03  | 03_CommentStyles         | Single-line (`//`) and multi-line (`/* */`) comment syntax             |
| 04  | 04_IOStreamBasics        | Using `#include <iostream>`, `std::cout`, `std::cin`, `std::endl`      |
| 05  | 05_BuildProcessDemo      | Understanding compile → link → execute through a multi-file concept    |
| 06  | 06_LanguageStandardCheck | Detecting which C++ standard your compiler is using                    |
| 07  | 07_WarningsDemo          | Why compiler warnings matter - code that compiles but has issues       |
| 08  | 08_CommonMistakes        | Frequent beginner pitfalls: missing includes, `std::`, confusing chars |
| 09  | 09_ConsoleWindowFix      | Keeping the console window open with `std::cin.get()`                  |
| 10  | 10_DesignBeforeCode      | A small well-planned program illustrating the development cycle        |
