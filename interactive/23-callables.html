Function Pointers and Functors

The things you can call in C++: function pointers, functors and std::function, what each one can hold, and when to use which. Lambdas, the shortest way to write most of them, come next.

Something you can call

Many functions take "something to call": std::sort takes a comparison, std::thread takes a task, a library takes a callback. C++ has several kinds of callable. They look the same at the call site, f(x), but they are different things underneath.

This lesson covers function pointers, functors and std::function. Lambdas come next and are the shortest way to write most of them.

Function pointers

Code lives in memory too, so a function has an address. A function pointer holds it, and calling through the pointer runs the function.

Passing a function pointer lets the caller choose the behavior at run time:

  • The pointer can point to any function with the same signature, and it can be changed while the program runs.
  • It has no state: the function sees only its arguments and globals. Giving descending a "limit" would need a global variable.
  • The call goes through the pointer, so the compiler usually cannot inline it.
C callbacksC libraries pass state with a void* argument next to the function pointer, because a plain function cannot carry any. Functors and lambdas remove the need for it.

Functors: objects you can call

A functor (function object) is a class with an operator(). An object of it is called like a function, and it can carry state in its members.

  • Each functor class is its own type, so a template such as std::count_if knows exactly which operator() runs and can inline it.
  • The cost: a whole class, written away from where it is used, for one small piece of logic.
  • The standard library ships ready-made ones: std::less<>, std::greater<>, std::plus<>. For example std::sort(v.begin(), v.end(), std::greater<>{}) sorts descending.
So what is a lambda?A lambda is a functor the compiler writes for you, in place: [limit](int x) { return x > limit; } is GreaterThan with limit as its member. See Lambdas.

std::function and std::invoke

A function pointer, a functor and a lambda are three different types. std::function<int(int)> is one type that can hold any callable taking an int and returning an int. That is called type erasure.

  • It can hold callables of different types in one container, or keep one behind an interface.
  • It may allocate when the callable does not fit its small internal buffer. Compiled with libstdc++: a callable holding one int allocated nothing, one holding a 64-byte array allocated once.

Cheat sheet

Answer aloud, then open.

What is a function pointer, and what can it not do?

The address of a function, 8 bytes, callable like the function. It cannot carry state: the function sees only its arguments and globals. The call goes through the pointer, so it is rarely inlined.

What is a functor?

A class with an operator(). Its objects are called like functions and keep state in their members. Each class is its own type, so templates can inline the call.

Why can a plain function pointer not carry a "limit" value for a comparison?

A function pointer is only an address. The function it points to receives its arguments and can read globals, nothing else. A functor or a lambda stores the limit as a member.

std::function vs a template parameter?

A template parameter keeps the exact callable type, so the call is inlined and nothing allocates. std::function erases the type: one indirect call, possible allocation, but it can store different callables behind one type.

How do you call a member function through a pointer?

With std::invoke(&Account::balance, acct), or (acct.*pmf)() for a pointer-to-member pmf. std::invoke works for every kind of callable.
