Class templates

Same idea for classes: vector<T>, map<K,V>, unique_ptr<T>.

  • Non-type parameters are compile-time constants (how std::array<int,5> knows its size).
  • Each instantiation is a separate, unrelated class. Members are instantiated only if called.
Why templates live in headersThe compiler needs the body at instantiation. In a .cpp, others see only a declaration: linker errors. Use headers, or explicit instantiation (template class Stack<int>;).

Cheat sheet

Answer aloud, then open.

What are alias templates and variable templates?

An alias template is a parameterised using (template<class T> using Vec = std::vector<T>;), which a typedef cannot be. A variable template is a constant or variable per type (template<class T> constexpr T zero = T{};); std::is_integral_v is one.

Full vs partial specialization?

Full: all template arguments fixed. Partial: a pattern with some parameters still free (Foo<T*>), allowed for class templates and variable templates but not for function templates (use overloading).

Why must template definitions be in headers?

The compiler needs the body to instantiate it in each translation unit that uses a particular type. If only the declaration is visible, no instantiation happens and the linker cannot find the function. Alternative: explicit instantiation in one .cpp.

What is a non-type template parameter?

A template parameter that is a compile-time value instead of a type, such as the N in std::array<int, N>. Each value gives a different type, which is why Stack<int, 8> and Stack<int, 9> are unrelated.

What is class template argument deduction?

Since C++17 the compiler can deduce the arguments of a class template from the constructor call: std::vector v{1, 2, 3} is a vector<int>. A deduction guide tells it how when the constructors alone are not enough.
