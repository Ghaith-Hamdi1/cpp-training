How to study every lessonRead a section, run its visualizer or simulator, predict the output before revealing it, then tick "I understand this section" in the lesson only when you could explain it aloud. End each lesson with its quiz and retry only the questions you missed. Press / to search. Use the "Try in Compiler Explorer" button on code blocks to run snippets (add -pthread for thread code). Time boxes are guides: if a block runs long, finish the quiz and move on.

Final review

Move semantics deep dive (optional)

Not needed for a first pass. When you want to master move semantics, follow the two reading guides: Effective Modern C++ move semantics path (books/Effective-Modern-Cpp-Meyers.pdf) and the C++ Move Semantics guide, Tier 1 (books/Cpp-Move-Semantics-The-Complete-Guide-Josuttis.pdf). The Josuttis book covers what Meyers leaves out: the moved-from state, value categories and writing move operations. About 75 pages of Josuttis plus a few Meyers items.

Books, going deeper

For a full read, follow the C++ roadmap: eight phases that match lessons 1 to 20 in order, each with the book chapters to read. For one book, use its reading guide: core language and library (books/Cpp-Primer-5th-Edition-Lippman.pdf), threading (books/Cpp-Concurrency-in-Action-2nd-Edition-Williams.pdf), foundations: pointers, OOP, templates, STL (books/Programming-Principles-and-Practice-Using-Cpp-3rd-Edition-Stroustrup.pdf), modern C++ items (books/Effective-Modern-Cpp-Meyers.pdf) and move semantics in depth (books/Cpp-Move-Semantics-The-Complete-Guide-Josuttis.pdf).
