Classes and encapsulation

A class bundles data with the functions that use it. Encapsulation: keep data private, expose only operations that keep it valid.

SpecifierWho can access
publiceveryone
protectedthe class itself and classes derived from it
privateonly the class itself (and its friends)

"Valid" is the class invariant (here: balance never negative). Hide the representation, let constructors build only valid objects, keep the public interface small. No invariant to protect? Use a plain struct.

struct vs classOnly the default access differs: struct public, class private. Use struct for plain data.

Member functions: this, const, static, friend

A member function is an ordinary function with one hidden extra parameter, this, the address of the object it was called on. static members have no this: they belong to the class.

  • const member function: callable on const objects, cannot modify members (except mutable). Make getters const.
  • static member function: belongs to the class, no this.
  • friend: access to privates. Use sparingly.

Constructors and destructors

A constructor sets an object up; the destructor (~Name()) runs automatically when its lifetime ends. This is the basis of RAII.

  • Use the initializer list: it initializes members directly. const and reference members can only be set there.
  • Members initialize in declaration order, not list order (-Wreorder).
  • explicit on a one-argument constructor blocks silent conversions.

A first look at RAII

Because the destructor always runs when the object goes out of scope, a class can acquire a resource in its constructor and release it in its destructor. You never have to remember to clean up. Cheat sheet

Answer aloud, then open.

What does const after a member function promise?

That the function does not modify the object: inside it this is a const T*. Only such functions can be called on a const object, so make every getter const.

In what order are objects constructed and destroyed?

Construction: base class first, then the members in declaration order, then the body of the constructor. Destruction runs in the exact reverse order.

Why use the member initializer list?

It initializes members directly instead of default-constructing and then assigning. const and reference members can only be set there. Members are initialized in declaration order, whatever order the list is written in.

What is a class invariant?

A condition that must hold for every valid object, such as "the balance is never negative". Keep the data private and let only the constructors and member functions change it, so the invariant cannot be broken from outside.

struct or class?

Only the default access differs: struct is public, class is private. Use struct for plain data and class when there is an invariant to protect.

What is RAII in one sentence?

Acquire a resource in the constructor and release it in the destructor, so the resource lives exactly as long as the object and is freed even when the function returns early or throws.
